# SportList (React)

React + Vite port of `sportlist-design-v2.html`.

```
npm install
npm run dev     # http://localhost:5173
npm run build
```

- `src/pages/` – Home, Explore, Profile, Register, Owner, Admin, Blog
- `src/components/` – Card, Icon (SVG sprite lives in index.html), nav/footer chrome
- `src/data.js` – sample data; `src/index.css` – original design CSS
